# Android Artifacts Cleaner

Windows-программа Jeronimo701 для поиска Android-артефактов на выбранных дисках: Android/data, Android/obb, LOST.DIR, .thumbnails и .nomedia. Интерфейс на PySide6. Удаление отмеченных элементов требует подтверждения в приложении. Это программа для Windows, не APK.

## Содержимое

- android_artifacts_cleaner.py — исходный код приложения.
- AndroidArtifactsCleaner.spec — исходные настройки сборки PyInstaller.
- generate_android_cleaner_icon.py и готовые ICO/PNG — генератор и ресурсы иконки.
- AndroidArtifactsCleaner.exe — существующая onefile-сборка, код которой сопоставлен с исходником; версия автором не задана, произвольный номер не назначен.
- LICENSE.txt / LICENSE-SCOPE.md, сторонние notices, SHA256SUMS.txt и PUBLICATION.json — происхождение, условия и проверки.

Для запуска исходника требуется Windows, Python и PySide6. Для повторной генерации иконки дополнительно требуется Pillow. Для сборки — PyInstaller и команда `python -m PyInstaller AndroidArtifactsCleaner.spec` в отдельной рабочей копии. Указанные зависимости не составляют полный воспроизводимый lock-файл.

Проверены синтаксис двух .py и .spec, соответствие встроенного кода EXE исходнику и поиск секретов. В ходе публикации приложение не запускалось, сканирование дисков и удаление файлов не выполнялись. Готовый EXE не пересобирался. Функциональная проверка на реальных дисках и подтверждение доверенной подписи издателя не заявляются.

Опубликовано как Secret Gist по правилу владельца. Доступен любому по ссылке; не является закрытым репозиторием с приглашениями. Исходная пользовательская папка не менялась.
