# Android Artifacts Cleaner

Поиск Android-артефактов на выбранных дисках с просмотром результатов и удалением отмеченных элементов.

## Возможности

**Выбор дисков.** Настройка области поиска перед обработкой.

**Подробные результаты.** Путь, тип, размер, признак пустой папки и причина обнаружения.

**Управление выбором.** Отметьте нужные строки или снимите выделение со всех результатов.

**Удаление с подтверждением.** Удаляются только отмеченные элементы после подтверждения в интерфейсе.

## Установка

Скачайте EXE и запустите его в Windows. Выберите диски и проверьте результаты поиска. Перед удалением просмотрите пути и причину обнаружения каждой выбранной строки: среди результатов могут оказаться нужные SDK, проекты или рабочие файлы.

## Статус выпуска

Авторский номер версии не задан: тег обозначает дату снимка. Опубликован существующий onefile EXE, встроенный код сопоставлен с исходником; приложение не пересобиралось. Сканирование и очистка настоящих дисков при подготовке публикации не запускались.

Контрольные суммы и сопроводительные лицензии находятся в файлах релиза.

## Сборка из исходников

```powershell
python -m pip install PySide6 pyinstaller
python -m PyInstaller AndroidArtifactsCleaner.spec
```

Главный исходник: `android_artifacts_cleaner.py`. Иконки создаёт `generate_android_cleaner_icon.py` (Pillow). Исторические материалы переноса находятся в `legacy-gist/`.
